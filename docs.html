BiliHistory

B站历史记录、关注列表、收藏夹本地化管理工具

项目介绍

BiliHistory 是一款面向 Windows 与 Linux 的 B站数据本地化管理工具。它通过 B站官方 API 抓取用户的观看历史、关注列表、收藏夹等信息，并以 CSV 形式持久化到本地，方便后续搜索、筛选、统计与回溯。

核心设计理念：数据 100% 存储在本地、增量抓取只增不删、30 天免费试用、单窗口 PyQt6 桌面应用。

功能说明

历史记录管理

一键抓取全部 B站观看历史（视频 / 直播 / 专栏），本地 CSV 存储，Excel 可直接打开；每次抓取自动生成快照备份，增量去重合并。

数据浏览与筛选

表格展示类型标签、标题、UP主、分类、观看进度、观看时间、BV号/房间号/文章ID；支持关键词搜索、类型筛选、时间筛选与多列排序。

我的关注

抓取并展示关注列表，3 列卡片网格异步加载头像，显示 UP主名称、签名、等级、认证信息。

我的收藏

树形分组展示收藏夹文件夹与收藏内容，支持视频、专栏等混合内容类型。

数据统计（我的画像）

基于本地 CSV 的纯本地统计：最常看 UP主、最常看分类、观看时段分布、完播率分析、最近 30 天观看趋势。

会员与授权

安装依赖（源码运行）

# 创建并激活虚拟环境（可选） python -m venv .venv .\.venv\Scripts\activate # Windows # source .venv/bin/activate # Linux/macOS # 安装依赖包 pip install -r requirements.txt

配置 Cookie

Cookie 用于抓取用户私有数据（历史记录、关注、收藏）。推荐方式：

# Windows set BILI_COOKIE=SESSDATA=xxx;DedeUserID=xxx # Linux/macOS export BILI_COOKIE="SESSDATA=xxx;DedeUserID=xxx"

或参照 .secrets.example.json 创建 .secrets.json：

{ "cookie": "SESSDATA=xxx; DedeUserID=xxx" }

.secrets.json 已被 .gitignore 排除，不会误提交。

使用方法

启动 GUI（推荐）

python gui_main.py

命令行模式

参数描述
--fetch仅获取历史记录，不进行处理
--process仅处理 CSV 文件，不获取新记录
--remove-duplicates移除重复记录（仅在 --process 模式下有效）
--sort按观看时间排序（仅在 --process 模式下有效）
--filter-type TYPE按类型筛选：video / live / article
--csv-file FILE指定 CSV 文件路径
python main.py 执行完整流程：获取历史记录并处理
python main.py --fetch 仅获取历史记录
python main.py --process --filter-type video 处理 CSV，仅保留视频类型记录

注意事项

首次使用：请确保已正确配置 B站 Cookie，否则无法获取私有数据。

API限制：为避免被B站API限制，请不要频繁执行获取操作。建议间隔至少1小时。

Cookie有效期：B站Cookie具有一定的有效期，过期后需要重新获取并更新配置。

增量更新：工具默认启用增量更新功能，只会获取新的历史记录，避免重复工作。

常见问题

如何获取B站Cookie？

  1. 打开浏览器，登录B站账号；
  2. 按 F12 打开开发者工具；
  3. 切换到 Network 选项卡；
  4. 刷新页面，找到任意一个B站的请求；
  5. 在 Request Headers 中找到 Cookie 字段，复制其值。

为什么获取不到历史记录？

  • Cookie 无效或已过期，请重新获取并更新配置；
  • 网络连接问题，请检查网络状况；
  • B站 API 限制，请稍后再试。
