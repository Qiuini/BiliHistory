B站历史记录工具

高效获取、处理和管理您的B站观看历史

项目介绍

这是一个功能强大的B站历史记录管理工具，能够帮助您获取、处理和分析您的B站观看历史记录。工具支持视频、直播和专栏三种类型的历史记录，并提供去重、排序、筛选等多种数据处理功能。

功能说明

数据获取

从B站API获取您的观看历史记录，包括视频、直播和专栏内容。支持分页获取和增量更新，避免重复获取已有的记录。

数据处理

提供多种数据处理功能，包括：

  • 移除重复的视频记录（基于BV号）
  • 按观看时间排序记录
  • 按内容类型筛选（视频、直播、专栏）

灵活配置

通过命令行参数，您可以灵活选择需要执行的功能，如仅获取数据、仅处理数据或执行完整流程。

安装依赖

在使用本工具前，请确保已安装以下依赖：

使用方法

您可以通过命令行参数来控制工具的行为。基本用法如下：

python main.py [选项]

命令行参数

参数 描述
--fetch 仅获取历史记录，不进行处理
--process 仅处理CSV文件，不获取新记录
--remove-duplicates 移除重复的BV号记录（仅在--process模式下有效）
--sort 按观看时间排序记录（仅在--process模式下有效）
--filter-type TYPE 按内容类型筛选（TYPE可选值：video, live, article；仅在--process模式下有效）
--csv-file FILE 指定CSV文件路径（默认：bilibili_history.csv）

示例用法

python main.py 执行完整流程：获取历史记录并处理（去重+排序）
python main.py --fetch 仅获取历史记录，不进行处理
python main.py --process 仅处理CSV文件（默认执行去重和排序）
python main.py --process --remove-duplicates --sort 处理CSV文件，移除重复记录并排序
python main.py --process --filter-type video 处理CSV文件，仅保留视频类型的记录
python main.py --csv-file my_history.csv 使用指定的CSV文件路径

注意事项

首次使用：请确保已在 bilibili_history_fetcher.py 中配置了正确的B站Cookie。

API限制：为避免被B站API限制，请不要频繁执行获取操作。建议间隔至少1小时。

Cookie有效期：B站Cookie具有一定的有效期，过期后需要重新获取并更新配置。

增量更新：工具默认启用增量更新功能，只会获取新的历史记录，避免重复工作。

常见问题

如何获取B站Cookie？

1. 打开浏览器，登录B站账号；

2. 按F12打开开发者工具；

3. 切换到Network选项卡；

4. 刷新页面，找到任意一个B站的请求；

5. 在Request Headers中找到Cookie字段，复制其值。

为什么获取不到历史记录？

可能的原因：

  • Cookie无效或已过期，请重新获取并更新配置；
  • 网络连接问题，请检查网络状况；
  • B站API限制，请稍后再试。
